  1. Personal project

    Climate Quest

    Checking the forecast for a trip tells you the weather but not what to do about it. Climate Quest closes that gap: pick a place and a set of dates, and it returns the conditions alongside a packing list derived from them — clothing, toiletries, electronics — adjusted for the kind of travel and activity planned. Built end to end, frontend and backend both.

    What I built

    • A React frontend showing temperature, humidity, and wind speed, with unit toggles between Celsius and Fahrenheit and between m/s and mph, plus date pickers and location selection.
    • Interactive Plotly charts, including a choropleth, so conditions read as a picture rather than a table of numbers.
    • A FastAPI backend that pulls historical weather from the Tomorrow.io API, averages conditions across the date range, and derives the packing list from the result.
    • Graceful handling for cities without enough data, so the app says so rather than showing an empty chart.
    • Docker Compose orchestrating both services and Poetry managing Python dependencies, so the whole thing comes up with one command.

    Stack

    • Plotly

    Moving a live platform between clouds

    What I built
